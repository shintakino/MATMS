# Leave, resource reservations and public availability

Status: the on-behalf, teacher directory and public-invitation revision is implemented and verified locally. Production still runs the previously deployed baseline recorded below; this revision has not been pushed or deployed.

## Current contract — on-behalf requests and expiring public links

- Teachers are directory people without login credentials, categorized SHS or JHS. Personnel can optionally link an existing active non-Viewer account. Admin can file their own leave without a pre-existing directory enrollment; the audited request transaction creates their personnel directory identity if necessary. Only Admin maintains directory identities, policy, closed dates and invitations. Employment does not grant archive roles or access.
- Admin and active linked personnel may file leave for any active, classified directory person. A request records its beneficiary, name/category snapshot and authenticated filing account separately. Personnel can read/edit/cancel requests they filed or that concern their linked person; only Admin sees the full private register and approves/rejects. Only Admin creates, edits, cancels and decides internal equipment/facility reservations, including reservations for teachers/personnel/themselves.
- Configure separate SHS/JHS/personnel daily limits; null is unlimited and zero closes a category. Keep the prior combined-teacher limit as an additional editable ceiling so migration cannot silently increase school capacity. Legacy unclassified teacher holds conservatively count against both teacher divisions and the combined ceiling. Preserve their snapshots; classify the directory person before new requests. Category changes require resolving future active leave first.
- Teachers and students need no accounts. Admin generates and copies a shareable URL; no email/SMS transport is introduced. Both link kinds allow one successful submission and expire after an Admin-selected 1–168 hours. Teacher leave links bind one SHS/JHS directory identity/version. Resource links permit choosing any currently published eligible resource and a private beneficiary name/category/purpose, including student requests. A public claim is unverified until Admin review; no login or internal-register access is granted.
- The public request page reads a 256-bit bearer token from the URL fragment and sends it only in POST bodies. Store its SHA-256 hash only; show the share URL once on creation. Link lists and audits never contain raw tokens/hashes. Lost URLs can be replaced and old links revoked. Use no-referrer/no-index metadata, no-store responses, bounded bodies and persistent per-IP/global request throttles. Do not put capability reads into shared query caches.
- Preview/availability/submission recheck expiry, revocation, usage and the active Admin issuer. A teacher link also rechecks the same active directory identity/version. Show whole-day/month availability, including this person's existing leave, category/combined capacity and closures. Unpublished ordinary leave calendars do not prevent an invited teacher from seeing their limited date availability. Resource links expose published availability only. No pending identities or other private details are disclosed.
- Public submission creates a Pending request, consumes the link, retains an opaque receipt, holds capacity and audits atomically under the existing scheduling lock. Failed validation/capacity/audit leaves the link usable. An exact operation-ID/fingerprint retry returns its original receipt within the valid capability lifetime; a different retry cannot reuse it. Validate expiry and current authorization even on replay. Revoke does not cancel an already filed request.
- Creation fingerprints stay immutable. Future active edits revalidate full ranges, replace holds, reset approval/unpublish and keep durable edit receipts. Staff may edit/cancel only their filed/self leave; resource changes and all decisions belong to Admin. No public edit/approval/cancellation authority is granted. Cancellation/retirement retains history and linked asset reservations never mutate inventory/custody.
- Directory migration preserves existing users, assignments, requests and snapshots. Existing teacher employment becomes an unclassified directory teacher without a login link; personnel enrollment retains its account link. Prior resource beneficiaries are snapshotted without inventing unknown employment. Replace the leave exclusion key with beneficiary person ID so different filing accounts cannot overlap the same person.
